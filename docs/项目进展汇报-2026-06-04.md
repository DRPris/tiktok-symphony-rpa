## 一、项目概述

### 1.1 项目定位

TikTok Symphony RPA 是一套面向 **TikTok 视频批量生成** 的自动化系统，旨在通过浏览器自动化技术，实现从商品信息导入到视频生成、审核、下载的全链路自动化，大幅降低视频制作人力成本。

### 1.2 技术选型

| 类别 | 技术方案 |
|------|---------|
| 运行时 | Node.js 22 + TypeScript 5.7 |
| 浏览器自动化 | Playwright 1.52（Chromium） |
| Web 服务 | Express 4.21 |
| 实时通信 | WebSocket 8.18 |
| AI 能力 | Qwen LLM + Qwen-VL 视觉模型 |
| 前端面板 | 原生 HTML/CSS/JS（Express 托管） |

### 1.3 核心架构

```
商品数据录入 → AI前置分析(卖点/商品图/受众) → 视频生成(模板/Agent双模式) → 人工审核 → 自动下载
```

- **双模式生成**：模板模式（复用 Symphony 模板库）与 Agent 模式（AI 对话驱动）
- **任务状态机**：`pending → running → waiting-generation → review → approved → downloading → completed`
- **并发处理**：5 标签页并发 Page 池，视频等待期释放 Page 供其他任务使用
- **人工审核闭环**：Web 审核面板支持一键通过/拒绝/重试

#### 受众分析技术细节

```
商品链接
  ├─ scrapeProductPage ──→ 页面文本 ──→ Qwen(文本模型) ──→ 文本路受众
  │                                                           │
  ├─ scrapeProductImages ──→ 图片URL ──→ Qwen-VL(视觉模型) ──→ 图片路受众
  │                                                           │
  └─────────────────── Qwen(融合) ◄──── 合并两路结果 ◄────────┘
                            │
                       最终受众描述 → 融入 Prompt 的 Target Audience 段
```

**三种自适应路径**：
- 文本+图片都有 → 双路并行 + LLM 融合（最佳效果）
- 仅有图片（本地商家文字少） → 纯视觉模型看图分析
- 仅有文本 → 纯文本模型分析（兜底）

**图片路 Qwen-VL 判断维度**：产品品类识别、目标人群推断（年龄/性别/生活方式）、使用场景、定位档次（包装设计暗示）、视频调性建议

**最终 Prompt 提交结构**：
```
{用户的prompt}
Product: {商品名}
Target Audience: {AI生成的受众描述}    ← 新增
Key Selling Points: {卖点}
```

## 八、总结

TikTok Symphony RPA 系统已完成 **全部核心功能开发**，包括双模式视频生成引擎、AI 前置分析（卖点 + 商品图 + **受众画像**）、批量导入与预览、审核面板、以及完整的稳定性自愈体系。最新迭代新增了 **AI 受众分析 Agent**，支持图文双路融合识别目标受众并自动注入 Prompt，特别优化了本地商家文字描述少、主要靠商品图片传达信息的场景。系统当前处于 **批量生产能力增强阶段**，为大规模（≥10条/批）视频批量生产做好准备。
